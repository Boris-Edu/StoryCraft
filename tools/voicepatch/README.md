# voicepatch: test bench for VoiceStudio voice patches

Finds sentence endings whose pitch doesn't fall (they sound unfinished after a cut) and replaces the last 1–3 words with a version in the speaker's voice, generated by a separately installed [VoiceStudio](https://github.com/debpalash/VoiceStudio). User guide: [docs/VOICESTUDIO.md](../../docs/VOICESTUDIO.md).

| File | Role |
|---|---|
| `voicepatch.py` | CLI: `doctor`, `detect`, `patch`, `batch` |
| `voicestudio_client.py` | HTTP client for VoiceStudio's local API (`/health`, `/engines/tts`, `/models`, `/watermark/status`, `/generate`, `/profiles`, `/convert`) |
| `audio.py` | ffmpeg I/O, YIN pitch tracker, ending-contour measure, room tone, crossfaded splice |
| `mock_voicestudio.py` | **Test stub, not VoiceStudio.** Same routes; speaks with macOS `say` and ignores the reference voice. Lets the pipeline run without VoiceStudio installed. |

Runs on StoryCraft's own venv (numpy, scipy, faster-whisper, requests); no new dependencies.

## How a patch is made

1. **Detect.** YIN pitch track of the timeline audio. Over the last words of each statement (≥ 0.45 s, ≤ 3 words), compare the last third of voiced frames with the first third, in semitones relative to the speaker's local median. Flagged when the pitch rises (Δ ≥ +0.8 st), or stays level (Δ > −1 st) while sitting above the median (≥ +1 st).
2. **Reference.** 5–14 s of the same timeline ending on a sentence whose pitch *falls*. The clone copies the reference's delivery, so a finished-sounding reference pushes the take toward a finished ending.
3. **Generate.** `tts`: the whole sentence, ending in a full stop, N seeds, `effect_preset=raw`. `convert`: the user's recording through `/convert` with `keep_delivery=true`, using a profile made from the reference (cached in `profiles.json`).
4. **Align.** faster-whisper word timestamps on each take; the target words are matched from the end with fuzzy matching.
5. **Choose.** Take score = how far the pitch falls − duration mismatch + text match.
6. **Fit.** Stretch to the original length when within 0.8–1.25× (keeps lip sync), RMS loudness match, room tone looped from the longest silence, 20 ms equal-power crossfades at quiet points.
7. **Re-measure.** Pitch contour of the patched audio, written to `report.json` next to the original.

## Run

```sh
PY="$HOME/Library/Application Support/StoryCraft/venv/bin/python3"
T="$HOME/Library/Application Support/StoryCraft/saves/timelines/<project>/<timeline>.json"
"$PY" tools/voicepatch/voicepatch.py doctor
"$PY" tools/voicepatch/voicepatch.py detect "$T"
"$PY" tools/voicepatch/voicepatch.py batch "$T" --out ~/Desktop/voicepatch --count 5

# without VoiceStudio:
python3 tools/voicepatch/mock_voicestudio.py --port 3999 &
"$PY" tools/voicepatch/voicepatch.py --url http://127.0.0.1:3999 batch "$T" --out /tmp/vp-mock
```
